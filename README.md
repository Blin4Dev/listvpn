# blinvpn

## Панель на отдельном сервере

При установке `install.sh` спрашивает «Установить панель на ОТДЕЛЬНЫЙ сервер?». Для уже установленного бота: `install.sh` → «Перенести панель на отдельный сервер».

Что нужно: сервер Debian/Ubuntu, A-запись домена панели на него, SSH под root (или пользователем с `sudo` без пароля).

Как работает:
- установщик один раз входит по паролю, добавляет отдельный ключ (`~/.ssh/blinvpn_panel_ed25519`, вход только с IP сервера бота) и дальше работает по ключу; пароль не сохраняется; отпечаток SSH-сервера подтверждается вручную;
- на сервере панели: Caddy (сам выпускает и продлевает сертификат), статика в `/var/www/blinvpn-panel` (атомарная смена версий, хранятся 3 последние);
- `/api/panel` сервер панели проксирует на сервер бота по HTTPS с проверкой сертификата и секретным заголовком; на сервере бота `/api/panel` открыт только для IP сервера панели и только с этим заголовком;
- настройки и секрет шлюза — в `.env.panel-remote` (права 600, в контейнеры не попадает);
- обновление бота (`install.sh` → 1) обновляет и панель на отдельном сервере.


## Caddy вместо nginx

Внешний прокси — Caddy: сам выпускает и продлевает сертификаты Let's Encrypt, certbot не нужен.
Конфиги: `/etc/caddy/Caddyfile` (глобальные опции, управляется установщиком) и `/etc/caddy/sites/*.caddy`
(BatmanVPN — `blinvpn.caddy`; свои сайты кладите туда же отдельными файлами).
Установка на nginx-версии переезжает автоматически при обновлении (`install.sh` → 1): если Caddy не получит
сертификат, nginx возвращается как был. Контейнеры мини-приложения и панели тоже на Caddy (`docker/Caddyfile.spa`).

## Порт HTTPS

При установке спрашивается порт (Enter = 443). Для готовой установки: `install.sh` → «Сменить порт HTTPS».
С портом не 443 адреса будут вида `https://домен:порт` (мини-приложение, панель, API), а порт 443 остаётся свободным (например, под Xray).
Порт 80 при этом всё равно нужен — через него Caddy получает сертификат. ЮKassa присылает уведомления только на 443/8443,
Telegram webhook — только на 443/80/88/8443, поэтому, если 443 занят, лучше выбрать 8443. Сервер панели работает на том же порту.
