# XBM (Xray Balancer Middleware) в составе BatmanVPN

Оригинальный автор: **Haxonate** — Xray Balancer Middleware 3.1.0.
Лицензия — файл [LICENSE](LICENSE) (MIT с дополнительными ограничениями:
в том числе запрет продажи и распространения ради коммерческой выгоды).

**Код изменён** (BatmanVPN). Изменения помечены в исходниках комментарием `[BatmanVPN]`:

- доработки из сборки для BatmanVPN: `auto_host_groups` (каждый хост — своя локация
  в порядке панели), правила из Templates → XRAY Json передаются клиенту, у каждой
  локации своё описание и свой Xray JSON, «Белые списки» в авто-выборе — только резерв;
- `src/panel-config.js` — настройки из панели BatmanVPN (раздел «Балансировщик»):
  пользователям видны только «Авто-выбор» и хосты, созданные в панели (`only_groups`);
  хост панели собирается из любых хостов Remnawave, может быть «Белыми списками»
  (в авто-выборе — только резерв), иметь описание и свой шаблон Xray JSON из Remnawave.
  Хосты выбираются в панели по списку (сверка по точному названию), изменения
  подхватываются на лету. Если название хоста Remnawave совпало с названием строки
  подписки, служебное имя хоста переименовывается («… · 2»);
- ответы XBM помечены заголовком `X-XBM: 1` (по нему установщик проверяет nginx);
- `config.json` — базовый конфиг BatmanVPN: `lte_patterns` пустой, `auto_host_groups` выключен,
  всё берётся из панели.
